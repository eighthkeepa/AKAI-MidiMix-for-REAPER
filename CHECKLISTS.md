# Чек-листы проверки на устройстве (v0.20)

Ставь галочку, если работает. Если нет, напиши рядом, что увидел. Всё это ещё не проверено на живом REAPER.

Подготовка: MIDI Mix включён как вход и выход, в проекте минимум 10 дорожек (есть папка, шина с посылами, дорожка с синтом, пара пустых), включён ReaImGui.

## 1. Новое в 0.20 (окно)

- [ ] В окне справа от полос есть колонка MASTER.
- [ ] Мастер-фейдер на устройстве двигает фейдер MASTER в окне, значение в дБ совпадает с REAPER.
- [ ] Кнопка M у мастера загорается, когда мастер заглушён в REAPER.
- [ ] Метры мастера живут, пока играет проект.
- [ ] Шкала фейдера доходит до +12 (при `fader_max_db = 12`). Подписи: +12, +9, +6, +3, 0, -3, -9, -20, -30.
- [ ] В Settings поставь «Fader top» на 6: шкала в окне укоротилась до +6, фейдер на устройстве по-прежнему дотягивается до верха.
- [ ] Верх фейдера на устройстве = +12 дБ в REAPER.
- [ ] Reset to defaults: «Fader top» стал 12.
- [ ] Метры и панорама: крутишь pan вправо, левый метр падает, правый остаётся. Влево, наоборот.
- [ ] Если при панораме оба метра падают слишком сильно (REAPER уже учёл панораму сам), выключи «Meters follow pan» в Settings и напиши мне.
- [ ] Галка «Meters show level after the fader» работает: выключил, метры не зависят от фейдера.

## 2. Окно в целом (0.19)

- [ ] Колонки в тёмных рамках, цвет и имя дорожки, иконка типа.
- [ ] Выбранная в REAPER дорожка заливает шапку своим цветом.
- [ ] Pan, ширина, посыл («имя» и N/N) показываются верно.
- [ ] Метры плавные, пик держится около 2 секунд, при пике выше 0 дБ надпись красная.
- [ ] Кнопки M, S и R/T/F загораются вместе с дорожкой в REAPER.
- [ ] Над дорожками из одной папки цветная полоса с названием папки.
- [ ] Нагрузка на процессор при открытом окне и играющем проекте нормальная (треки не заикаются).
- [ ] Кириллица в именах дорожек читается.
- [ ] Закрытие окна крестиком не останавливает скрипт, Close script останавливает.
- [ ] Pause / Resume в окне работает, в строке состояния ACTIVE / PAUSED / NO DEVICE верно.

## 3. Диоды

- [ ] Mute горит у заглушённого трека, у солированного мигает.
- [ ] Пока держишь Solo, на ряду Mute горят солированные (ноты 2, 5, 8…).
- [ ] Rec горит у взведённого трека.
- [ ] Диоды Rec 1..N на секунду показывают номер посыла.
- [ ] Bank Right мигает на втором банке и дальше, на первом оба Bank-диода тёмные. Чем дальше банк, тем чаще мигание.
- [ ] На паузе оба Bank-диода горят ровно, остальные тёмные.
- [ ] Круг при старте: Mute 1..8, потом Rec 8..1.
- [ ] Выход: Mute и Rec дважды мигают. REAPER при этом не подвисает (скрипт на выходе стоит около 0,7 секунды).

## 4. Основное управление

- [ ] Фейдеры, pan, ширина, посылы, подхват (трек не прыгает).
- [ ] Mute, Solo + Mute полосы, Solo коротко (соло банка).
- [ ] Rec срабатывает при отпускании кнопки.
- [ ] Solo + Rec: весь банк в текущем режиме Rec-ряда.
- [ ] Solo + Send All снимает все соло.
- [ ] Bank Left / Right двигают на 8, удержание прыгает в первый или последний банк, Solo + Bank двигает на 1.
- [ ] Обе Bank вместе: stereo pan всему банку. Solo + средняя ручка: stereo pan одному треку.
- [ ] Ширина слышна на дорожках в режиме stereo pan. Проверь новую дорожку без явного stereo pan.
- [ ] Rec N + Send All: следующий посыл одного трека.
- [ ] Send All двойным нажатием: пауза и возврат.
- [ ] Удалил дорожку в банке: банк пересобрался, следующая подтянулась.
- [ ] Дорожки, скрытые в миксере, пропускаются.

## 5. Режимы Rec-ряда

- [ ] Двойное нажатие Solo: arm → send mute → FX bypass → arm. Горит 1, 2 или 3 диода Rec.
- [ ] Send mute глушит именно показанный в окне посыл.
- [ ] FX bypass обходит всю цепочку дорожки.
- [ ] Переключатели «Rec arm / Send mute / FX bypass» в окне делают то же самое.
- [ ] Первое нажатие Solo из двойного не оставляет соло банка включённым.

## 6. Режим «инструмент»

- [ ] Send All (одно нажатие) переключает режим, ряд Mute (в инструмент) или Rec (в микшер) вспыхивает.
- [ ] Переключатели Mixer / Instrument в окне работают.
- [ ] Learn из окна: клик по ячейке, тронул параметр, ячейка запомнила.
- [ ] Learn с устройства: галка «Learn mode», покрутил ручку, тронул параметр.
- [ ] Ручка двигает параметр плагина с подхватом.
- [ ] Привязки живут после сохранения и открытия проекта.
- [ ] Привязка на плагин другого трека и на мастер.
- [ ] Mute полосы открывает и закрывает окно плагина, диод горит, пока окно открыто.
- [ ] Rec полосы выбирает трек, диод горит у выбранного.
- [ ] Обе Bank вместе: play/stop. Solo + Send All: в начало.
- [ ] Сброс: крестик в ячейке, Solo + ручка, Clear all.
- [ ] Цвет ячейки одинаковый у параметров одного плагина.

## 7. Типы дорожек

- [ ] Audio, Instrument, Folder определяются правильно.
- [ ] Bus (есть входящие посылы) определяется правильно.
- [ ] VCA: сделай настоящий VCA master (Track grouping → VCA master), он определяется.
- [ ] Separator не управляется контроллером, диоды тёмные.
- [ ] Клик по типу под полосой меняет тип, звёздочка = вручную, после последнего типа снова авто.
- [ ] Тип по layout дорожки работает (если у тебя есть layout с separator, bus, vca в названии).

## 8. Подсветка банка

- [ ] `spacers`: пробелы над банком и под ним, видны в микшере и в окне дорожек.
- [ ] `markers`: два красных трека «MidiMix», едут за банком, в банк не входят, нормально выглядят как separator.
- [ ] `color`: дорожки банка подкрашены, исходные цвета возвращаются при уходе из банка, на паузе и при выходе.
- [ ] `none`: ничего не добавляется.
- [ ] Принудительно останови скрипт (Terminate), запусти снова: всё помеченное убралось, цвета вернулись.
- [ ] Undo не засорён лишними шагами.

## 9. Микшер и банк

- [ ] Микшер прокручивается к началу банка.
- [ ] `follow_mixer`: прокрутил микшер руками, банк поехал за ним.
