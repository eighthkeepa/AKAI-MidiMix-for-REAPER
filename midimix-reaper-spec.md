# Akai MidiMix → REAPER (Lua): спецификация v0.1

Реализация: один Lua-скрипт (defer-цикл) + окно ReaImGui. Устройства пока нет, поэтому первым делом пробный скрипт: он пишет в консоль ноты/CC каждой кнопки и по очереди зажигает диоды.

## Банк
- 8 полос. Размер банка в конфиге; можно меньше 8, пустые полосы тёмные и ничего не делают.
- Считаются только треки, видимые в миксере.
- Банк привязан к позиции первого трека. Удалили трек в банке — следующий подтягивается.
- Выделение треков не используем. Цвета треков не трогаем.
- Метка банка: пробел (spacer) над первым и под последним треком банка. Переносится при смене банка. Свойство `I_SPACER` (проверить на практике, в том числе в миксере). Скрипт помечает свои пробелы и убирает старые при старте и выходе.
- Окно ReaImGui: имена, цвета, уровни, состояния. Миксер прокручивается к началу банка.
- Опция на потом: если соло/rec есть в другом банке, мигает bank-диод в ту сторону. Рамка поверх треков — эксперимент на потом.

## Фейдеры и ручки
- Фейдеры: громкость трека. Мастер-фейдер: мастер.
- Ручки и фейдеры работают с подхватом: значение меняется, когда ручка дошла до текущего.
- Нижний ряд: pan.
- Средний ряд: ширина панорамы (только в режиме stereo pan). Solo + поворот средней ручки: этот трек переключается в stereo pan. Обе bank-кнопки вместе: весь банк.
- Верхний ряд: посылы (sends). Страница N — N-й посыл трека. Короткое нажатие Send All — следующая страница по кругу. Страниц столько, сколько посылов у трека с наибольшим числом посылов в банке. У трека без N-го посыла ручка молчит. Текущая страница видна в окне. Опция в конфиге: сопоставлять посылы по имени получателя (например «Reverb»), а не по порядку.

## Кнопки
- Mute, Rec arm: по каждому треку.
- Solo + Mute N: соло трека N.
- Solo коротко (без Mute): соло всего банка.
- Solo + любая Rec: взвести/снять rec на весь банк.
- Solo + Bank: сдвиг на 1 трек.
- Solo + Send All: снять все соло.
- Send All, удержание около секунды: вкл/выкл. Выключено — контроллер полностью отключён от треков, положения ручек запоминаются. Нажатие Send All присылает положения всех ручек, это используется для подхвата.

## Светодиоды
У Solo и Send All диодов нет. Mute — янтарные, Rec — красные, Bank — янтарные. Мигание делает скрипт.
- Mute: горит — трек заглушён.
- Соло: диод Mute у солированных треков мигает. Пока держишь Solo, диоды Mute показывают соло-состояние ровным светом.
- Пустая полоса: диод всегда тёмный.
- Bank-диоды: горят — работает, тёмные — выключено.
- Кнопка на панели REAPER показывает состояние скрипта.
- Номер страницы посыла: после короткого нажатия Send All на 1–1,5 секунды загораются диоды Rec с первого по N-й (N = номер страницы). Потом диоды Rec возвращаются к обычному показу взведённых треков.
- В окне над ручкой каждой полосы: название получателя посыла и «Посыл N из M»; если посыла нет — прочерк.

## Открытые вопросы

2. Проверить на железе: ноты/CC кнопок, LED rec arm (на форуме Ardour писали, что иногда не горят), ширину в stereo pan, spacer в миксере.
